### Your own AI Parametric Modeler

Parashell is a fork of FreeCAD. It builds on the FreeCAD codebase under the LGPL2+ license.
All *proprietary* additions are stored in the Mod directory, compiled to Cython .so and .pyd files (for speed, of course 😉)

For more info see https://www.parashell.cloud
